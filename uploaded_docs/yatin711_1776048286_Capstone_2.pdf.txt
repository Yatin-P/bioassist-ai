AI-Powered Medical Chatbot Capstone Report Problem Statement This project focuses on developing a full-stack AI-powered medical chatbot that provides accurate and context-aware medical information. The system integrates a vector database for semantic search, conversational memory for context retention, and a custom user interface. The goal is to improve accessibility to reliable healthcare guidance and enhance user interaction. Literature Review Recent advancements in artificial intelligence and natural language processing have enabled the development of intelligent healthcare chatbots. Vector databases support efficient semantic retrieval of medical knowledge, while conversational memory improves personalization and continuity in user interactions. Annotated Bibliography 1. Jurafsky, D., & Martin, J. H. (2023). Speech and Language Processing – Provides foundational NLP concepts used in chatbot development. 2. Kalyan, K. S., et al. (2021). AI in Healthcare – Discusses chatbot applications in patient interaction and support. 3. Johnson, J. (2022). Vector Databases in AI – Explains semantic search and retrieval systems. 4. Zhang, Y., et al. (2020). Conversational AI – Highlights the role of memory in improving chatbot effectiveness. Conclusion The AI-powered medical chatbot demonstrates how modern AI technologies can improve healthcare accessibility and user engagement. Future improvements may include integration with real-time medical data sources and enhanced diagnostic capabilities.
